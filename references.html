Resources

A growing list of readings, tools, and examples we draw on throughout the course. Each week’s class page links to its assigned readings.

Examples to learn from

  • Pingfan Hu, “Agentic Skills”: how he writes skills for images, slides, and HTML, including generating images with Gemini and finishing them with code so they come out the same every time.
  • Pingfan Hu, “Agentic Engineering” Part 1, Part 2, and Part 3, plus “Agentic Workflows”.
  • Pingfan Hu, “How to Make a Personal Website” (with Quarto).

How LLMs work

  • 3Blue1Brown, Neural networks video series.
  • Transformer Explainer and the tokenizer playground: interactive demos in the browser.
  • Timothy B. Lee and Sean Trott, “Large language models, explained with a minimum of math and jargon”.
  • Messeri & Crockett (2024), “Artificial intelligence and illusions of understanding in scientific research”, Nature.

Git, GitHub, and the web

  • GitHub Desktop docs
  • GitHub Pages docs
  • Quarto websites

Agents and skills

  • Claude Code docs
  • Anthropic, “Equipping agents for the real world with Agent Skills”
  • markitdown: convert documents to Markdown so an agent can read them with fewer tokens.

Tools for building things

  • Images: the Gemini API image generation docs (Nano Banana) and Pillow for editing images with Python.
  • Animation: Manim and matplotlib animations.
  • Sound and music: music21 and pydub.
  • HTML to PDF: Playwright for Python and WeasyPrint.
  • Data visualization: polars, plotnine, and holtzy/dataviz-skills.
  • Slides: Quarto presentations.

AI and education

  • The MIT report on AI and education.
  • Advait Sarkar, “How to stop AI from killing your critical thinking” (TED).
